├── 영화관광_*.xlsx                          ← 팀원 제공 원본 데이터/수집표

    ├── golden_time_calculator.py           ← 규칙기반 골든타임 계산기 (실전 사용)

## 실행 방법

```bash

python anomaly_classifier_final.py    # 최종 분류 모델 성능(AUC)
```
