# 콘텐츠 골든타임 예측 모델

**「2026 한국관광 데이터랩 활용 경진대회」출품작**

콘텐츠(영화) 흥행이 시작된 시점부터 실제 방문객이 급증하기까지 걸리는 시차 — **"골든타임"**을 한국관광 데이터랩 방문자 데이터와 검색·박스오피스 데이터로 조기에 포착해, 지자체가 관광객 급증에 미리 대응할 수 있게 돕는 모델입니다.

---

## 1. 문제의식

영화 하나가 흥행하면 배경지에 관광객이 몰리지만, 지자체가 이를 인지하고 대응(안전관리 인력 배치, 임시 편의시설 등)하기까지는 시차가 존재합니다. 이 시차 동안 안전사고·불만 민원이 발생하기 쉽습니다.

- **핵심 질문**: 검색량이 튀는 시점(사람들의 관심이 움직이기 시작하는 시점)을 조기에 포착하면, 실제 방문객이 몰리기 전에 지자체가 미리 준비할 수 있지 않을까?
- **대표 사례**: 영화 〈왕과 사는 남자〉 흥행 → 강원 영월군(실제 배경지) 방문객 급증. 같은 영화의 세트장인 경북 문경새재에도 별도로 관광객이 몰린 이중 관광효과 사례.

## 2. 한국관광 데이터랩 활용 방식

| 활용 데이터 | 용도 |
|---|---|
| 지역별 방문자 현황(외지인·현지인 방문자수, 전년동월 증감률) | 콘텐츠 배경지의 실제 방문객 변화 측정 |
| 인접 지역(대조군) 방문자 현황 | 계절·전국 추세와 콘텐츠 효과를 분리하기 위한 비교 기준 |

*(관광데이터랩 데이터에 Google Trends 검색량·KOBIS 박스오피스 데이터를 결합해 분석 — 대회 취지의 "관광 이외 분야 데이터 융복합" 사례에 해당)*

## 3. 분석 방법 및 검증 결과

작은 표본(독립 사례 4개)이라는 한계를 정직하게 인정하고, 이를 통계적으로 우회하기 위해 3단계로 검증했습니다.

### ① 규칙기반 골든타임 계산기
평시 대비 표준편차 N배를 초과하는 날을 "검색 급증일"로, 이후 지자체 공식대응·방문객 피크일까지의 간격을 계산.

| 사례 | 검색급증일 | 공식대응/방문피크 | 골든타임 갭 | 검증 상태 |
|---|---|---|---|---|
| 영월(왕과 사는 남자) | 2/8 | 3/6 공식대응 | **26일** | ⭐ 대조군 비교로 강한 효과 검증(+25.1%p) |
| 신안(자산어보) | 3/31 | 방문 급증 확인 | — | ⭐ 대조군 비교로 강한 효과 검증(+19.3%p) |
| 남해(소풍) | 2/7 | 2/10 방문자피크 | 3일 | 비수기 시점이라 신뢰 가능 |
| 예산(살목지) | 4/8 | 4/14 지자체 야간 출입통제 공지 | 6일 | 정성적 근거 강함(정량 검증은 면단위 집계 한계) |

### ② 대조군 비교(Difference-in-Differences)
콘텐츠와 무관한 인접 지역(대조군)의 같은 기간 변화와 비교해, 계절·전국 추세를 제거한 순수 콘텐츠 효과를 추정.

| 사례 | 대상 자체 변화 | 대조군 평균 변화 | 순수 효과(DID) |
|---|---|---|---|
| **영월** | +23.7%p | −1.4%p | **+25.1%p** |
| **자산어보** | +33.8% | +14.5% | **+19.3%p** |
| 파묘 | +12.0% | +7.3% | +4.8%p |
| 예산 | −16.1%p | −18.3%p | +2.2%p |

**종합(랜덤효과 메타분석)**: 영화 흥행 시 배경지 방문객은 평균 **+12.1%p** 증가 (95% 신뢰구간 +2.4~+21.8%p)

### ③ 이상탐지 분류 모델
"이 지역-이 시기가 콘텐츠 효과로 방문객이 튄 것인가"를 판정하는 모델. 대조군(12개 지역)+콘텐츠 배경지(4개 사례)의 월별 관측치를 모아 64건의 학습 데이터셋을 구성하고, Leave-One-Case-Out 방식으로 검증.

- **최종 성능: 평균 AUC 0.786** (0.5=무작위 수준, 1.0=완벽 판별)
- 더 복잡한 모델(다중 피처 결합, RandomForest, GradientBoosting 등)을 6가지 시도했으나 표본 부족(사례 4개)으로 전부 성능이 오히려 하락함을 확인 → 가장 단순한 모델이 최종 채택됨. 개선 과정 전체는 `golden_time_project/experiments/`에 투명하게 기록.

## 4. 기대 효과 및 확산 가능성

- 관광지 안전문제 해결: 방문객 급증 예상 시점을 사전에 포착해 안전인력·시설을 미리 배치
- 타 사례 확산 가능성: 영화뿐 아니라 드라마·유튜브 등 다른 콘텐츠 유형, 대조군 비교 방법론 자체는 축제·팝업스토어 등 다른 지역 이벤트 효과 측정에도 적용 가능

## 5. 저장소 구성

```
travel-golden-time/
├── README.md                              ← 이 파일
├── 골든타임_프로젝트_최종정리.md            ← 전체 분석 결과 상세본
├── 골든타임_프로젝트_쉬운설명.md            ← 통계 용어 없이 풀어쓴 버전
├── 영화관광_학습용_추가_완성본.xlsx         ← 원본 데이터
└── golden_time_project/
    ├── golden_time_calculator.py           ← ① 규칙기반 골든타임 계산기
    ├── did_analysis.py                     ← ② 대조군 비교(DID) 분석
    ├── anomaly_classifier_final.py         ← ③ 최종 채택 분류 모델 (AUC 0.786)
    ├── transfer_learning_chronos.py        ← 사전학습 시계열 모델(Chronos)로 독립 교차검증
    ├── convert_teammate_daily.py           ← 원본 데이터 전처리
    ├── config.py                           ← 사례별 메타데이터
    ├── experiments/                        ← 분류 모델 개선 과정 전체 기록(실패한 시도 포함)
    └── data/raw/                           ← 분석에 사용한 정제 데이터(Google Trends, 관광데이터랩 방문자수, KOBIS 박스오피스)
```

## 6. 실행 방법

```bash
cd golden_time_project
pip install -r requirements.txt
python golden_time_calculator.py      # ① 사례별 골든타임 갭 계산
python did_analysis.py                # ② 대조군 비교(DID) 결과
python anomaly_classifier_final.py    # ③ 최종 분류 모델 성능(AUC)
```
